# Digital Breakfast — Site V2

Site institucional em HTML5, Tailwind CSS, CSS3 e JavaScript puro, com ícones Lucide.

## Arquivos
- `index.html`: estrutura e conteúdo
- `styles.css`: identidade visual, animações e componentes
- `app.js`: menu mobile, header, progresso de rolagem e animações
- `assets/`: logotipos, favicon e foto

## Publicação
Envie todos os arquivos e a pasta `assets` para a pasta pública do domínio na Hostinger.

## Observações
- Tailwind e Lucide são carregados por CDN.
- Atualize os links de LinkedIn e artigos antes da publicação.
- O site é responsivo e não depende de build.
